# 🎬 ONE-CLICK DESKTOP LAUNCHER

## Quick Setup (2 Minutes)

### Step 1: Clone Repository
```bash
git clone https://github.com/Tom100014/brownssocialmediaapp.git
cd brownssocialmediaapp
```

### Step 2: Create Desktop Launcher
```bash
bash setup-desktop.sh
```

### Step 3: Configure API Keys
Edit `.env.local` and add your API keys:
```bash
GOOGLE_API_KEY=your-key-here
TIKTOK_OAUTH_TOKEN=your-token-here
INSTAGRAM_OAUTH_TOKEN=your-token-here
```

### Step 4: Click Button to Launch! 🎯

## Troubleshooting

### "Node.js not found"
→ Install Node.js: https://nodejs.org/

### "Permission denied"
→ Run: `chmod +x launcher.sh setup-desktop.sh`

### "API keys not set"
→ Edit `.env.local` and add your keys

### "Port 3000 already in use"
→ Kill the process or use a different port
